# Threads-агент NEMESH — як запустити (v1, тільки текст)

Схема така сама, як з твоїми ботами: файли → GitHub → Railway → працює.

## Що робить агент
- 2 рази на день бере наступну тему з банку (файл `temy.md`)
- Шле тобі в Telegram на підтвердження: 👍 Опублікувати / ✍️ Переписати / ❌ Скасувати
- Після 👍 — публікує в Threads
- Попереджає, коли в банку лишилось ≤3 теми
- Сам оновлює токен Threads раз на місяць (щоб не протух)

---

## КРОК 1. Новий бот у Telegram (5 хв)
1. У Telegram напиши **@BotFather** → `/newbot`
2. Дай ім'я (напр. `NEMESH Threads`) і юзернейм (напр. `nemesh_threads_bot`)
3. BotFather дасть **токен** — збережи. Це буде `TELEGRAM_TOKEN`.

## КРОК 2. Дізнатись свій Telegram ID
Твій ID з паспорта: **428771141** (це `OWNER_CHAT_ID`).
Якщо не впевнений — після запуску напиши боту `/whoami`, він покаже.

## КРОК 3. Репозиторій у GitHub
1. Створи новий приватний репозиторій, напр. `nemesh-threads-agent`
2. Залий туди 4 файли: `bot.py`, `requirements.txt`, `Procfile`, `.python-version`
3. Залий також `temy.md` (банк тем)
4. Відкрий `temy.md` у GitHub → натисни **Raw** → скопіюй адресу з рядка браузера.
   Це буде `BANK_URL` (виглядає як `https://raw.githubusercontent.com/...`).

## КРОК 4. Railway
1. Новий сервіс з цього репозиторію (як робив з ботами)
2. У **Variables** додай 4 змінні:

| Змінна | Значення |
|---|---|
| `TELEGRAM_TOKEN` | токен з BotFather (крок 1) |
| `OWNER_CHAT_ID` | `428771141` |
| `THREADS_ACCESS_TOKEN` | токен, який ти згенерував у Meta |
| `BANK_URL` | Raw-посилання на `temy.md` (крок 3) |

3. (Рекомендовано) Додай **Volume**, змонтований на `/data` — щоб пам'ять
   про опубліковані пости не скидалась при перезаливці. Без цього агент
   після редеплою може запропонувати вже опубліковану тему.

## КРОК 5. Перший тест
1. Дочекайся, поки Railway задеплоїть (статус Active)
2. У Telegram напиши своєму боту `/start`, потім `/post`
3. Агент має прислати перший пост із кнопками
4. Натисни 👍 — і перевір свій Threads. Якщо пост з'явився — ВСЕ ПРАЦЮЄ 🎉

|---|---|---|
| `POST_HOUR_1` | 10 | година першого поста (Київ) |

## Команди бота
- `/post` — запропонувати пост зараз (для тесту)
- `/status` — скільки тем лишилось
- `/whoami` — показати твій Telegram ID
